# 4Ss Engineering Services website

Static Next.js website for 4Ss Engineering Services, built from the approved Release 7.1 Content Master and Design & Developer Specification.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy on Vercel

Import this directory into Vercel. The framework preset, build command, and output settings are detected automatically.
